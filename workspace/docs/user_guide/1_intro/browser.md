## 지원 브라우저

SmartEditor2는 현재 유지보수되는 최신 안정 버전의 브라우저를 지원한다.

표 1 지원 브라우저와 운영체제

| 운영체제 | 브라우저 |
| --- | --- |
| Windows, macOS, Linux | 최신 안정 버전의 Chrome, Firefox, Edge |
| macOS, iOS | 최신 안정 버전의 Safari |
| Android | 최신 안정 버전의 Chrome |

Internet Explorer 계열은 지원하지 않는다. 브라우저별 예외 처리가 필요한 경우 user agent 대신 Selection, Range, Pointer Event 등 실제 기능의 지원 여부를 기준으로 판단한다.

SmartEditor2 버전에서는 기존의 SmartEditor Basic 0.3.17 버전에서 제공하던 기능을 개선하고, 새로운 기능을 추가하였다. 또한 Editor 모드(WYSIWYG)와 HTML 모드 외에 TEXT 모드를 추가하여 다양한 방식으로 글을 편집할 수 있다.
